# Team Task Manager

A full-stack Team Task Manager application built using React, Spring Boot, and MySQL.

## Features
- User Signup & Login
- Role-based access (Admin / Member)
- Create Projects
- Create & Assign Tasks
- Task Status Tracking
- Dashboard Statistics
- Responsive UI

## Tech Stack

### Frontend
- React.js
- Axios
- CSS

### Backend
- Spring Boot
- Spring Security
- REST APIs

### Database
- MySQL

## Deployment
- Frontend: Vercel
- Backend: Railway
